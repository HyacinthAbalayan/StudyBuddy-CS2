
STUDYBUDDY – APPLICATION FLOW

1. MAIN MENU
   The user can choose from the following options:
   - Manage Tasks
   - Record Study Session
   - View Productivity Report
   - Exit

2. MANAGE TASKS
   The user can:
   - Add a new academic task.
   - View all saved tasks.
   - Update task information.
   - Delete an existing task.

3. RECORD STUDY SESSION
   The user enters:
   - Subject
   - Study duration
   - Date of study session

4. PRODUCTIVITY REPORT
   The application displays:
   - Total study hours
   - Number of completed tasks
   - Task completion percentage
   - Most studied subject

5. DATA STORAGE
   All tasks and study sessions are saved
   in a JSON file for future use.

6. EXIT
   The user can safely close the application.
